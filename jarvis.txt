3. BRAIN (LLM LAYER) — core/brain.py
================================================================================

3.1 OllamaBrain (lines 34-289)
  Backend: Local Ollama API (http://localhost:11434)
  Models: Configurable fast/smart/deep (default: phi4-mini)
  Chat: POST /api/chat with streaming response
  Tool calling: Parses [TOOL]name(args)[/TOOL] tags from text output
  Tool loop: Multi-round execution with dedup detection

3.2 GroqBrain (lines 292-526)
  Backend: Groq Cloud API (groq Python SDK)
  Models: Configurable fast/smart/deep (default: llama-3.1-8b-instant / 70b)
  Chat: client.chat.completions.create() with native tool calling
  Tool loop: Multi-round execution with set-based dedup

3.3 Shared Features (both brains)
  SYSTEM_PROMPT: Concise FRIDAY persona with tool descriptions
  select_model(): Keyword-based model routing (deep/code -> 70B, quick -> 8B)
  _relevant_tools(): Keyword-map filters tools (40+ categories) to stay under token limits
  chat_with_tools(): Up to 10 rounds, executes tool calls, feeds results back
  Duplicate detection: Set of (tool_name + JSON args) prevents infinite loops
  Fallback: No-keyword-match returns default tools (web_search, fetch, read, run, launch, browse)

3.4 Keyword Map Categories
  system: cpu/memory/disk/battery/network/process/volume/wifi/clipboard/etc.
  shell: cmd/command/terminal/powershell/run/execute/script
  file: read/write/edit/list/move/copy/delete/mkdir/find/grep
  web: search/google/bing/fetch/url/http
  git: commit/push/pull/clone/branch/repo
  browser: chrome/firefox/edge/open/launch/app/instagram/facebook/youtube
  code: python/script/run/sandbox
  memory: remember/recall/forget
  plan: task/step/goal/objective
  news: headline/wikipedia/current event
  stock: market/price/trade
  scrape: extract/link
  security: firewall/port/audit
  research: deep/analyze
  ocr: image/spreadsheet

10. DATA FLOW
================================================================================

USER -> Wake word detected (voice) or text input
  -> Assistant._handle_command()
    -> Built-in? -> Execute directly
    -> AI? -> _process_with_ai()
      -> Brain.select_model() -> fast/smart/deep
      -> Brain._relevant_tools() -> filter tools by keywords
      -> Brain.chat(conversation + tools) -> LLM response
        -> Tool calls? -> Execute handler -> Append result -> Repeat
        -> Text? -> Return to user
      -> Up to 10 rounds, dedup detection breaks loops
    -> SpeechEngine.speak() (TTS output)
  -> Conversation saved to conversations/ (JSON)

11. KEY DESIGN PATTERNS
================================================================================

1. DUAL BRAIN: GroqBrain (cloud, fast, 70B) and OllamaBrain (local, fallback)
   — Switched via config.json provider field

2. LAZY LOADING: All 13 tool modules + monitoring loaded on first use
   — _lazy_*() methods reduce startup time

3. TOOL REGISTRY: Each module exposes get_tool_definitions() + get_handler(name)
   — OpenAI-compatible function calling schema

4. KEYWORD FILTERING: Both model selection AND tool filtering use keyword maps
   — Prevents token limit issues with 108 tool definitions

5. DUPLICATE DETECTION: Set-based tracking of (tool_name + sorted JSON args)
   — Prevents infinite loops from repeated tool calls

6. MULTI-ROUND EXECUTION: chat_with_tools() loops up to 10 rounds
   — Model can chain multiple tool calls per user request

7. STARK PERSONA: Full Iron Man theming — arc reactor, Mark 86, FRIDAY quotes
   — Enhances user engagement

8. SAFE SANDBOX: Code execution blocks dangerous modules
   — Wrapped __import__ allows only approved imports

9. CHROME PROFILE MANAGEMENT: Multi-profile support with persistent storage
   — launch_app opens chrome://newtab; browse_url opens URLs as new tabs

10. FALLBACK CHAIN: launch_app -> Start-Process -> https://URL via Chrome
    — Handles app names, file paths, and website names transparently
